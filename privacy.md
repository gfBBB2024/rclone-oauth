# Privacy Policy

This is a personal-use application configured to access Google Drive through rclone.

- **Data accessed:** Google Drive file metadata and file contents, as authorised by the account owner.
- **Purpose:** To copy and back up selected Google Drive files to the owner's local computer.
- **Storage:** Downloaded files are stored locally on the owner's computer.
- **Data sharing:** This configuration does not intentionally share Google Drive data with third parties.
- **Authentication:** OAuth credentials are stored locally by rclone and used to access Google Drive.
- **Data retention:** Local backup files are retained and managed by the owner.

For questions about this personal application, contact the application owner using the support email provided in its Google OAuth configuration.
